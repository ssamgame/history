## 2. 고려편 안에 어디에 넣을까 — 선택지 3개

시간 순서: 993 서희(1장) → 1010 양규(2장) → 1018~19 강감찬(3장, 끝에 나성·천리장성 S20) → **1104~1109 윤관** → 1225~ 몽골(4장) → 1236~51 대장경(5장) → 1270~73 삼별초(6장). 어떤 선택지든 윤관은 **3장과 지금 4장 사이**다. 3장 끝의 천리장성(`chapters/ch3/script.js:77`) 다음이라 "북쪽 국경을 지켜라"로 자연스럽게 이어진다.

저장·이어하기 구조 참고(코드 확인):
- 장 순서는 `id`가 아니라 `no`로 정한다(`chapters/index.js:126~132` `isUnlocked`가 같은 편의 `no - 1`을 본다). 조선편이 이미 `j3`을 2번째(no 2)에 두고 있어, **id를 바꾸지 않고 새 장을 사이에 끼울 수 있다.**
- 결과 카드는 그 편 목록의 모든 장을 마쳤는지로 뜬다(`isSessionDone`, `chapters/index.js:135~137`). 목록에서 뺀 장의 옛 기록은 무시된다.
- 이어하기는 `save.data.current.id`로 장을 찾고, 목록에 없으면 버린다(`core/main.js:145~154`). 옛 기록 판별 정규식 `/^ch\d$/`(`core/save.js`)는 `ch7`도 고려편으로 본다.
- 6장 고정을 검사하는 테스트: `tests/courses.test.js:10`(편마다 6장), `tests/screens.test.js:10`(CHAPTERS 6), `tests/screens.test.js:20`(SESSIONS[1] 6줄). 장 이름→얼굴 표는 `core/quizview.js:14`(윤관 추가 필요).

### ㉠ 3장 뒤에 새 장을 넣어 7장 편

- 모양: 새 장 id `ch7`(폴더 `chapters/ch7`), `no: 4`. 지금 ch4~ch6은 no 5~7. 결과 카드 7줄.
- 장점: 윤관 장을 넉넉히(10~12분) 만든다. 다른 장을 건드리지 않는다. 삼별초도 그대로.
- 단점: 고려편만 7장(약 80분)이 되어 "편마다 6장·결과 카드 6줄" 규칙(CLAUDE.md, 테스트 3곳)을 바꿔야 한다. 수업 차시 계획이 바뀐다. 이미 3장까지 마친 학생은 지금 4장이 새 4장(윤관)을 마쳐야 열린다(이어하기 중이던 ch4는 `main.js`가 잠금 검사 없이 이어 주므로 문제 없음).
- 장 시간: 새 장 10~12분, 편 전체 +10분.

### ㉡ 3장을 "거란을 물리치고 여진에 맞서다"로 늘림

- 모양: 3장에 둑 놀이·귀주 놀이 다음 세 번째 부분으로 별무반을 붙인다. 장 수·id 그대로.
- 장점: 저장·결과 카드·테스트 영향이 가장 적다(결과 카드 3줄만 고침).
- 단점: 3장은 이미 놀이 둘(둑, 귀주의 바람)로 약 9분이다. 별무반까지 넣으면 **14~15분**으로 선생님이 정한 12분을 넘는다. 거란(1019)과 여진(1104)은 85년 떨어진 다른 사건이라 한 장에 묶으면 학생이 "강감찬이 여진도 물리쳤다"로 헷갈릴 위험이 크다(역사 틀림 위험). **권하지 않는다.**

### ㉢ 6장 편 유지 — 윤관 새 장을 4번째로, 삼별초는 마지막 장 끝으로 줄여 합치기 (추천)

### 윤관 장 놀이 아이디어 (어느 선택지든 같음, 약 10~11분)

1. **도입 장면(읽기, 점수 없음, 30초)**: 1104년, 넓은 들판에서 여진 기병이 빠르게 돌아 들어와 고려 보병 줄이 물러난다(불길·피 없이 먼지·물러남). 윤관 한 줄: "말 탄 적을 이길 새 군대가 필요하다." — 사실(1104 패배·건의) 그대로.
2. **핵심 놀이 ①「별무반 편성」(끌어 놓기, 약 3분)**: 고을 사람들이 차례로 온다(말을 끄는 농부, 말을 탄 관리 집 아들, 말 없는 젊은이, 승려 등). 학생은 사람을 **신기군 깃발(말)·신보군 깃발(창)·항마군 깃발(염주)** 중 알맞은 곳으로 끈다. 규칙은 사실 그대로: **말이 있으면 신분과 관계없이 신기군, 말이 없으면 신보군, 승려는 항마군.** 단계: 1단계 사람마다 말이 잘 보임 → 2단계 "말을 끌고 오는 노비"(신분과 관계없이 신기군이 핵심 깨달음) → 3단계 줄이 빨라지고 사람이 섞여 옴. 틀리면 그 사람이 고개를 젓고 힌트("말이 있나요?") — 두 번 틀리면 말·염주 표시가 반짝임(쉬운 모드).
   - 각색 경계: 사람마다의 이름·사연은 가상 인물(초록). 세 부대가 **어떤 싸움에서 각각 무엇을 했는지**는 기록을 확인 못 했으니 **부대별 활약 장면은 만들지 않는다**(빨강). 편성 기준만 놀이로.
3. **핵심 놀이 ②「북쪽으로 진군」(이동, 약 2분)**: 지킴이가 별무반 행렬 맨 앞에서 이정표 길을 따라간다(지금 kit의 drive·`post` 방식 재사용 가능). 길 위 여진 기병이 오면 **신기군을 앞세우는 신호**(때 맞추기)로 물리친다 — "기병에는 기병"이라는 별무반을 만든 까닭과 이어짐. 지명은 쓰지 않고 "동북쪽 국경"만.
4. **마무리 놀이「성 쌓기」(누르기, 30초~1분)**: 동북쪽 땅에 성 자리가 9개 켜지고 하나씩 눌러 쌓는다(1장 강동 6주 짓기와 같은 부품이라 만들기 쉬움). **성 이름표·정확한 위치는 쓰지 않는다**(학설 갈림). 
5. **읽기(점수 없음)**: 1109년 반환 컷 2장(여진 사신이 돌려 달라고 함 / 멀리 떨어진 성을 지키기 어려움 → 돌려줌). 학생이 "이겼는데 왜 돌려줬지?"를 생각하게 하는 한 줄 질문으로 끝.
6. 퀴즈 2개(1절 예시).
- 지킴이 옷: 별무반 신보군 병사 옷(투구+갑옷)으로 장마다 옷만 바뀌는 원칙에 맞음.

| 백성 옷 | **흰색·연한 베 색의 저고리(유)·바지(고)·긴 겉옷(포)**. 색을 많이 쓰지 않음. | 고려 남자 서민 옷이 포·유·고, 흰 모시 옷이 많았다는 설명(국가 복식 자료 요약). 세부 형태는 단순화 |
| 장인 | 백성 옷 + 앞치마·두건 + 도구로 구분 | 장인 복식 기록은 찾지 않음. 도구(칼·망치·붓·옻칠통)로 직업을 보여 주면 충분 |
| 거란 병사 머리(곤발) | **보이지 않게 털모자로 덮는 것을 권장.** | 거란의 곤발(정수리를 깎고 옆머리 일부만 남김)은 위키 수준 설명만 확인했고, 정확한 모양은 확인 못 함. 머리가 드러나면 청나라 변발(뒤로 땋은 긴 머리)로 잘못 그리기 쉬움 → 그건 틀림이므로 모자로 덮어 피함 |
| 여진 병사(새 윤관 장) | 털모자·털 깃 + **말 탄 모습**이 핵심. 거란과 옷 색만 다르게. | 여진 머리 모양을 그리면 청나라 변발과 헷갈림 → 모자로 덮기 |
| 흥화진의 실제 모습 | **실제 모습은 알려져 있지 않다**고 보고 "고려 국경 성" 일반형으로. 산을 끼고 돌로 쌓은 성벽 + 성문 + 문루 정도. | 흥화진은 지금 북한 평안북도 의주 일대(위원면)로 추정되는 정도만 검색됨. 발굴·복원 그림 자료는 찾지 못함. 안내판에 "이렇게 생겼다"고 쓰지 않음 |
| 옹성 | **넣어도 되지만 "흥화진에 옹성이 있었다"고 설명하지 않는다.** 성문 앞 반달 모양 둘레 벽 정도로 단순하게. | 옹성은 고구려 성에도 있었고 고려 성곽에도 쓰였다고 보는 것이 일반적이나, 흥화진에 있었다는 근거는 찾지 못함 |
| 치(성벽에서 튀어나온 부분) | 성벽 몇 곳을 네모로 튀어나오게 하는 정도는 무방 | 치는 고구려 산성부터 있던 시설(검색 요약). 고려 천룡산성 등에서 치성 확인 보고 있음 |
| 망루 | 나무 망루·문루 정도로. 조선 수원 화성식 공심돈·포루 같은 독특한 건물은 넣지 않음 | 화성 시설은 1796년 조선 것이라 고려에 넣으면 틀림 |
| 처인성·항파두리 | **흙으로 쌓은 낮은 성(토성)** 으로 | 처인성은 작은 토성, 항파두리는 흙성(S13) — 기존 장면과 같음 |
| 건물 지붕 | 기와(궁궐·관청·절)와 초가(백성) 구분이면 충분. 고려 다포 지붕 세부는 정하지 않음 | 고려 목조 건물은 남은 것이 매우 적음(부석사 무량수전 등). 세부는 단순화 |

## 5. 확인하지 못한 것

1. **한국민족문화대백과사전·우리역사넷 원문**: 이 환경에서 두 사이트 주소를 찾지 못해(DNS 실패) **열어 보지 못했다.** S71·S72 후보의 항목 번호(E0023022·E0032714·E0066626)와 내용은 검색 결과 요약으로만 견줬다. 넣기 전 원문 확인 필요.
2. **「윤관」·「동북9성」 백과사전 항목 주소와 우리역사넷 항목**: 찾지 못함.
3. **별무반 설치 달(1104년 12월인지)**, 9성 반환 달(1109년 7월이라는 자료가 있음): 연도만 확인, 달은 확인 못 함 → 게임에는 연도만 쓴다.
4. **세 부대(신기군·신보군·항마군)의 실제 싸움에서의 역할 차이**: 확인 못 함 → 놀이에 부대별 활약 장면을 만들지 않는다.
5. **비상 교과서가 윤관 부분에서 쓰는 정확한 낱말**(예: "동북 9성" / "동북 9성을 쌓았다" / "별무반" 언급 여부, 9성 반환을 쓰는지): 선생님께 교과서 문장 확인 부탁.
6. **고려 병사 갑옷·투구 실물과 거란 곤발의 정확한 모양**, **흥화진 성 구조**: 학술 자료를 찾지 못함 → 4-2절대로 단순화.
7. 교과서에 삼별초 자체(사건)가 나오는지, 처인성·충주성이 둘 다 나오는지는 선생님 답에 없었다 → ㉢을 고르기 전에 한 번 여쭤보면 좋다.
