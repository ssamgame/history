# 근대·일제 강점기·현대편 설계 (2026-10-23)

## 목표

교사가 쓰는 비상 5-2 사회 교과서(98~145쪽, 출처 S51)를 따라 조선 뒤부터 현대까지를 세 편, 18장으로 잇는다. 교과서에 있어도 5학년에게 불필요한 세부는 빼고, 교과서에 없어도 흐름에 꼭 필요한 내용(현대편 6장)은 더한다.

## 만드는 방식

- 고려·조선편은 장마다 장면과 진행을 손으로 짰지만, 새 18장은 부품 상자 `chapters/kit/`로 만든다.
  - `town.js`의 `buildTown`이 배치표(땅, 길, 건물, 사람 무리, 인물, 안내판, 흩뿌린 나무)를 3D로 세운다.
  - `chapter.js`의 `makeKitChapter`가 진행을 맡는다: 인물에게 차례로 말 걸기 → 미니게임 부품들 → 결과 → 퀴즈 2개.
- 장마다 `script.js`(대사·미니게임 카드·퀴즈, 모든 서술 문장에 출처)와 `chapter.js`(배치표)만 쓴다.
- 미니게임 부품은 choose(맞는 카드 고르기), sort(나누기), place(자리 놓기), order(차례 맞추기), gauge(때 맞춰 누르기), collect(빛나는 곳 찾아가기) 여섯 가지다. 모두 터치만으로 끝낼 수 있고, 틀려도 다시 하면 된다.

## 내용 원칙

- 교과서 서술(S51)을 먼저 따르고, 교과서 밖 내용은 여러 자료에서 확인된 것만 쓴다. 현대편 6장은 4·19 혁명(S58), 5·18 민주화 운동·6월 민주 항쟁·직선제(S59), 경부고속도로(S60), 서울 올림픽(S61)을 따른다. 이산가족 찾기 방송(S62)은 5장 안내판에 넣었다. 2026-10-24 선생님 의견으로 근대편 3장에 고부 관아 장면(S65 고부민란: 조병갑은 농민군이 온다는 소식에 전주로 피신했으므로 맞서 싸우는 장면이 아니라 달아나는 모습)과 1·2차 농민 운동 역사책(S64 동학농민운동: 황토현·전주성·전주 화약과 집강소·다시 봉기·우금치·전봉준 체포)을 더했다.
- 2026-10-25 3단계 검토로 출처를 더했다: S66 거란 2차 침입 철수(현종 친조 약속, 고려편 2장), S67 1945년 이승만·김구 귀국 날짜(현대 1장), S68 1951년 서울 재탈환·휴전 회담(현대 4장), S69 1885년 서울~인천 전신(근대 5장), S70 5·10 총선거(만 21세 이상 투표권, 현대 2장). 판정 근거는 `2026-10-25-stage3-review.md`.
- 2026-10-29 현대 3~6장을 새 체험으로 바꾸며(D-50~D-53) 출처를 더했다: S71 유엔군 전투 부대를 보낸 16개 나라(국가기록원, 현대 3장 유엔군 도착), S72 군사 분계선과 남북 2km 비무장 지대(정전 협정 70주년 기사, 현대 4장 휴전선 긋기), S73 1960년대 가발·옷·신발 수출과 1964년 수출의 날(국가기록원, 현대 6장 수출 공장), S74 서울 올림픽 개회식 굴렁쇠(현대 6장). 현대 5장 이산가족 찾기의 할아버지·동생 이름과 고향은 꾸민 이야기다.
- 전쟁·학살 장면은 그리지 않는다. 사람들의 이야기와 안내판으로 전한다.
- 생각이 갈린 일(이승만·김구)은 옳고 그름을 매기지 않고 누구의 생각인지 나누기만 한다.
