## 검토 방법
- 장마다 뽑은 글을 처음부터 끝까지 읽고, 내용 원칙(측우기·훈민정음 1443/1446·척화 주화·저고여·"서희"·"친하게 지내다"·1장 선택지·불길 없는 전투)을 따로 찾아 확인했다 → **원칙은 30장 모두 지켜짐**(어긋난 곳 없음).
- 사실은 `content/sources.js` 출처 메모와 맞대 보고, 흔히 알려진 사실과 다르거나 장 안의 시간 흐름과 어긋나는 것만 골랐다(웹 검색은 하지 않음 → 사실 항목은 모두 검토 팀원 확인 필요).
- 긴 문장 기준: **한 문장이 공백을 빼고 50자를 넘으면** '긺'(그런 문장 30개, 그중 고칠 만한 것만 넣음). 전체 문장 길이 가운값은 26자.
- 출처(src)가 달린 해설·퀴즈·인물 대사는 선생님 결정대로 **뜻을 바꾸지 않는다** → '맞춤법만' 또는 '검토팀 확인'으로 표시.

## 문제 아님(확인만)

- 언덕 위 덤불·바위가 화면 위쪽에서 떠 보이는 곳(k4·k5·i2·h1·h6 오른쪽 위): 땅 메시와 비교해 보니 땅에 붙어 있음. 가파른 언덕 끝이라 그렇게 보일 뿐이라 고치지 않음.
- `?debug=ch4-scene`이 빈 초록 화면: 개발용 바로가기에서만 그렇고 실제 진행(탐험부터)은 정상. 필요하면 개발 도구만 손봄.
- k1 PALACE 무대의 서양 건물·기선: '다른 때의 일' 칸을 일부러 나타낸 것(배치표 주석). 다만 기선 모양은 14번 참고.
