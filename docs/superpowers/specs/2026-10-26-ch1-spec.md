# 표준 작업 명세 — 고려 1장 「서희의 담판」 새로 만들기 (2026-10-26, 기획 담당)

> 근거: `HANDOFF-redesign.md` 0·1·4절, `redesign-plan.md` 1장, `minigame-map.md` 고려 1장(말 받아치기, 선생님 허락), `redesign-review.md` 1장·Q1·Q2, 본보기 `ch2-pilot-spec.md`와 2장 시범 코드(`chapters/ch2/chapter.js`, `chapters/kit/ops.js`). 이 명세 밖의 별도 기획 보고서는 쓰지 않는다.

## 1. 수정 목표
1장을 2장 시범과 같은 틀(지킴이 · 머리 위 말풍선 · 두 번 틀리면 쉬워짐 · 도장 + 지혜 카드 · 역사책 없음)로 다시 짓고, 지금의 "보기 고르기 2번"을 **놀이 「말 받아치기」** 하나로 바꾼다. 필수 대사 7줄 이하, 한 장 12분 이내(추정 8~9분).

## 2. 수정 항목

### 2-1. 흐름 (`runChapter` 단계 이름 `intro/explore/minigame/quiz`와 저장 호환 그대로)
출정 카드(해설 2줄, 지금 `intro` 그대로) → **지킴이 고르기**(처음 한 번, 건너뛰기 가능) → 작전 준비(진영 탐험 ≤2분) → **담판: 말 받아치기**(≈3분) → 거란군 물러남 · 강동 6주 세우기 연출(자동, 15초) → 퀴즈 2문항 → 도장 · 지혜 카드(`finale`).
- 결정: 지킴이 고르기는 **1장이 편의 첫 장이므로 1장에서** 한다. 2장 코드는 건드리지 않는다. 저장 키는 2장과 같은 문자열 `'goryeo-game:guardian'`을 1장 `chapter.js`에 상수로 따로 적는다(2장 파일을 import하지 않는다). 이미 골라 두었으면 건너뛴다(`savedGuardian`).
- 결정: 학생 옷은 `guardianLook(id, 'soldier')`(서희 곁의 젊은 병사). 서희·소손녕·병사·관리·궁수의 생김새는 `content/characters.js` 그대로.
- 역사책 없음. 사건 설명은 말풍선 · 안내판 2개(`signGangdong`, `signSong`, 선택 읽기) · 퀴즈 해설로만.

### 2-2. 작전 준비 (탐험)
- 병사(소손녕 80만 대군 큰소리, S16) → 서희(땅을 떼어 줄 수 없다 · 직접 담판, S17) 순서로 말 걸기 → 나루터(빛나는 원)로 가면 담판으로. 관리(S17)·궁수(S19)·안내판 2개는 **선택 말풍선**(안 들어도 진행, 들으면 수첩에 모임).
- 결정: 대화는 모두 `ops.talk` 머리 위 말풍선(한 번에 2줄 이하). 큰 안내판 "강동 6주"가 길 한가운데서 화면을 가리는 문제(진단 문서)는 **길 옆으로 옮긴다**(장면 쪽, 걷는 길 `bounds`와 나루터 위치는 그대로).
- **필수 대사 7줄 이하**(정의: 반드시 듣게 되는 말풍선 줄 수. 출정 카드 2줄과 놀이 안 소손녕·서희 말풍선은 제외). 아래 3절 표대로 **6줄**:
  병사 1 + 서희 1 + 담판 앞 해설 1 + 담판 뒤 해설 1 + 물러남 2.

### 2-3. 놀이 「말 받아치기」 (새 부품, 약 3분)
**규칙(결정)**
- 서희(고정 카메라, 서희와 소손녕이 마주 선 그림)와 소손녕이 말을 주고받는다. 학생은 서희의 곁에서 **알맞은 대답 구슬을 소손녕 쪽으로 쏘아 올려 말을 받아친다.**
- 판은 **2판**: ① 고구려 땅 문제(`negotiation.q1`) ② 거란과 친하게 지내지 않는 까닭(`negotiation.q2`). 소손녕의 말은 말풍선으로 뜨고 **말 공**(글자 공) 하나가 서희 쪽으로 천천히 날아온다.
- 아래에 **대답 구슬 3개**(기존 `options` 3개, 글자 그대로, 순서 섞기). 구슬을 **끌어 올리거나 누르거나 키보드 1·2·3**으로 고른다. 세 방법 다 같은 동작.
- 맞는 구슬(기존 정답 문장 그대로): 말 공이 되튕겨 가 소손녕 쪽으로 가고, 서희가 `reply` 한마디, 위 가운데 **기세 게이지**(`opsGauge`, 고려 대 거란)가 고려 쪽으로 움직인다. 시작 0.5, 판마다 +0.25, 두 판 맞히면 1.0.
- 틀린 구슬: 말 공이 서희 앞에서 터지며(먼지 · 글자 튐, 불길 없음) 게이지가 소손녕 쪽으로 0.1, 기존 `hint` 한 줄이 뜨고 **같은 판을 다시**(말 공 새로). 소손녕 표정이 굳는 연출은 얼굴 모양을 바꾸지 않고 말풍선 흔들림으로만.
- 제한 시간(결정): 1판은 말 공이 **끝까지 오지 않게** 멈춰 둔다(읽을 시간). 2판은 말 공이 **12초**에 걸쳐 오고, 닿기 전에 못 고르면 틀린 것과 같이 처리(힌트는 다시 읽어 줌). 쉬운 모드에서는 시간 제한 없음.
- **두 번 틀리면 쉬워짐**: `runRounds(ctx, rounds, play, { easyAfter: 2 })` 그대로 쓴다(옵션은 이미 있다). 쉬운 모드 = **틀린 구슬 하나가 흐려져 못 고름**(구슬 2개) + 2판 제한 시간 없음. 안내: "이번에는 조금 쉽게 해 볼게요."(이미 `runRounds`가 말함).
- 기록: `{ firstTryCorrect, firstTryTotal: 2, easyModeUsed }` 지금 형식 그대로. 판마다 **첫 고르기에서 맞았는지**를 장 쪽 클로저로 세어 `firstTryCorrect`에 넣는다(`runRounds`의 `first`는 전체값이라 판별이 안 된다).
- 새 문장 금지: 구슬 글은 기존 `options[].text`, 소손녕 말은 기존 `prompt`, 서희 대답은 기존 `reply`, 힌트는 기존 `hint`뿐. 놀이 설명(`showHowTo`)은 규칙 안내(사실 아님) 한두 줄만.
- 서희를 싸우는 사람으로 그리지 않는다(칼 · 활 없음, 손짓 · 고개 끄덕임 정도). "서희 장군" 금지, 호칭 "서희".

**부품 위치(결정)**: 새 파일 `chapters/kit/rally.js`에 `export function rally(ctx, { prompt, options, speakerAnchor, targetAnchor, gauge, easy, seconds, scene })` 하나를 **추가**한다. 기존 `chapters/kit/*`와 `ops.js`는 한 줄도 바꾸지 않고 `ops.js`의 `runRounds · talk · opsGauge · popText · shake · finale · pickGuardian · savedGuardian · usePlayerFigure`를 import해서만 쓴다. 대답 구슬 · 게이지 CSS는 `rally.js`가 스스로 넣는다(`ensureStyle` 방식, 스타일 id `kit-rally-style`). 새 파일이므로 배포 때 `PRECACHE`에 넣는다(개발이 마지막에 `core/precache.js`).

- 투구 · 모자 얼굴이 보여야 한다(`tests/faces.test.js` 통과).

## 8. 결정 기록 (선생님께 일일이 묻지 않음)
