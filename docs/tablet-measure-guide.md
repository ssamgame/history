# 갤럭시 탭 S6 Lite 성능 측정 안내 (v64, 배포 전)

학생 주소(https://ssamgame.github.io/history/)는 **바꾸지 않고**, 작업 중인 판을 다른 주소로 열어 잽니다.
다른 주소에서 열기 때문에 **학생 저장 기록(진행·별점)과 섞이지 않습니다.**

> 주소가 안 열리거나 흰 화면만 나오면 그 화면을 알려 주세요. 다른 방법(클로드 미리보기 페이지, 로그인 필요)을 준비하겠습니다.

## 준비 (한 번만)
1. 탭을 **충전기에서 뺀 상태**로, 배터리 50% 이상, **절전 모드 끄기**(설정 → 배터리).
2. 다른 앱을 모두 닫기(최근 앱 버튼 → 모두 닫기).
3. 크롬 브라우저를 쓰기. 탭을 **가로**로 두기.
4. 탭이 차가운 상태에서 시작(오래 쓴 직후라면 10분 쉬었다가).

## ① 한 번에 재기 (가장 먼저, 약 3분)
1. 크롬 주소창에 ①의 주소를 입력하고 엽니다(조금 기다리면 3D 화면이 뜹니다).
2. 빨간 **측정 시작**을 누릅니다.
3. 약 3분 동안 **화면을 만지지 않습니다**. 위쪽 글자가 "근대 3장 … 화질 medium 재는 중…"처럼 바뀝니다.
4. "다 쟀어요"가 나오면 **복사**를 누릅니다. (복사가 안 되면 아래 글을 길게 눌러 전체 선택 → 복사, 또는 **파일로 저장**.)
5. 복사한 글을 그대로 보내 주세요.

재는 것: 근대 3장 동학 마을(탐험)·근대 3장 무대·근대 5장 전차 길·현대 5장 피란민 마을을 화질 보통 → 낮음 → 높음으로 각 10초(진입 3초 + 안정 7초), 그리고 역사책 첫 쪽(미리 찍기 없이 가장 나쁜 경우)과 쪽 넘김.

## ② 오래 하기 (발열·끊김, 5분)
1. ①을 마친 뒤 10분 쉬어 탭을 식힙니다.
2. ②의 주소를 열고 **측정 시작** → 5분 동안 화면을 만지지 않습니다.
3. 끝나면 **탭 뒷면 위쪽을 손으로 만져 보고** "미지근함 / 따뜻함 / 뜨거움" 중 하나를 결과와 함께 적어 주세요.
4. **복사**해서 보내 주세요. 결과의 "1분마다" 표에서 분이 갈수록 FPS가 떨어지는지 봅니다.

## ③~⑤ 게임하며 재기 (실제 진행 그대로)
1. 주소를 열면 오른쪽 위에 `FPS 58 · 5초 57 · 멈칫 0 · medium` 같은 **검은 띠**가 보입니다(학생 주소에는 안 나옵니다).
2. 평소처럼 걷고, 대화하고, 미니게임과 역사책을 해 봅니다.
3. 다음을 눈으로 봐 주세요.
   - 걸을 때 끊기는지
   - 미니게임 무대로 바뀌는 순간 멈칫하는지
   - **역사책 앞 안내 대사가 나올 때** 멈칫하는지(첫 쪽 그림을 그때 미리 찍습니다)
   - 역사책을 펼 때·넘길 때 그림이 바로 뜨는지
   - 검은 띠 끝의 화질 글자가 `medium` → `low`로 바뀌는지(자동 조절이 작동하면 바뀝니다)
4. 검은 띠를 누르면 표가 펼쳐집니다. **복사**를 눌러 보내 주세요.
5. 화질 단추(낮음·보통·높음)로 바꿔 같은 곳을 다시 걸어 비교할 수 있습니다(이 단추는 저장되지 않습니다).

## 병목 가르는 법 (잰 값 / 추정 구분)
- **잰 값**: FPS, 멈춘 프레임 길이, render() 호출에 쓴 CPU 시간, 그리기 횟수·삼각형, 장면·무대 짓기 시간, 역사책 그림 시간, 도형·텍스처 수, JS 메모리(크롬만).
- **잴 수 없음**: GPU가 실제로 그리는 시간, GPU 메모리, 기기 온도 → 아래처럼 **추정**만 합니다.
1. **GPU 그리기 부담(추정)**: FPS는 낮은데 render() CPU 시간은 짧고(5ms 미만), 낮음 화질에서 FPS가 크게 오르면 → 그림자·선명도 부담일 가능성이 큼.
2. **CPU 부담(잰 값)**: render() CPU 시간이 길면(8ms 넘음) → 그리기 횟수·물체 수 부담.
3. **역사책 그림 생성 부담(잰 값)**: '역사책 첫 그림' 시간.
4. **장면 전환 멈춤(잰 값)**: 진입 직후 가장 긴 프레임, '장면 짓기·무대 짓기' 시간.
5. **장시간 저하(추정)**: 1분마다 FPS가 떨어지고 탭이 뜨거움 → 발열로 기기가 스스로 느려짐. JS 메모리·도형 수가 계속 오름 → 정리 안 된 것.

## 결과에 따라 고칠 순서와 그래픽 변화 (결과를 본 뒤 하나씩)
| 병목 | 먼저 해 볼 것 | 그래픽 변화 |
|---|---|---|
| GPU 부담 | 보통 화질의 선명도 1.25배 → 1.0배 | 아주 조금 덜 또렷함 |
| GPU 부담(그림자) | 보통 화질 그림자 지도 2048 → 1024 | 그림자 가장자리가 조금 흐려짐 |
| 역사책 첫 그림 | 게임 화면용 렌더러로 그림 찍기(새 3D 화면을 만들지 않음) | 그림 색감이 조금 달라질 수 있음 |
| 장면 전환 멈춤 | 무대를 몇 프레임에 나눠 짓기 | 변화 없음 |
| 발열 | 화면 갱신을 초당 30번으로 제한하는 선택 | 움직임이 조금 덜 매끄러움 |
| 메모리 증가 | 무대·장면 치울 때 정리 보강 | 변화 없음 |

고칠 때마다 **같은 탭·같은 장면·같은 화질**로 ①을 다시 재어 전후를 비교합니다.
