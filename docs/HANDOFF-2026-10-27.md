## 0. 지금 상태 (한 줄)
작업 브랜치의 파일은 **학생 사이트에 배포된 main(`e2a3b81`, 캐시 판 `goryeo-v65`)과 똑같다.** 2026-10-26~27에 했던 「고려~현대 다시 만들기」는 선생님이 직접 해 보시고 "원하는 느낌이 아니다"라고 하셔서 **모두 되돌렸다.** 학생 사이트는 처음부터 v65 그대로였다(다시 만들기는 배포하지 않았다).

## 1. 꼭 지킬 것 (선생님 규칙)
- 사용자는 경북 포항 초등 5학년 담임 선생님(육상 · 생존수영 · 줄넘기 인증제 담당). 답은 **한국어, 쉬운 말**.
- **결정이 필요한 질문은 바로 답하지 말고 두세 가지를 먼저 여쭌다.** 혼자 정하고 멀리 가지 않는다.
- 보고 형식: 수정 내용 / 파일 / 전후 차이 / 테스트 / 결과 / 남은 문제 / 다음 우선순위.
- **main 병합 · 학생 사이트 배포는 선생님이 명시적으로 승인할 때만.** 미리보기 아티팩트(학생과 함께 쓰는 링크)는 다시 올리지 않는다.
- 실제 태블릿 측정 전에는 그림자 해상도 · 선명도 배율 · 풀나무 수 · 역사책 그림 방식을 바꾸지 않는다.
- 역사 사실: 출처(`src`) 달린 문장만. 내용 원칙은 `CLAUDE.md` '내용 원칙' 그대로(서희 · 저고여 · 측우기 · 근엄한 표정 · 불길 없이 등).
- 커밋 메시지는 한국어. 테스트는 고친 곳부터, 배포 전에는 전체.

## 2. 학생 배포판(v65)에 들어 있는 것
`CLAUDE.md`의 설명이 이 판과 맞는다. 요점만:
- 다섯 편 × 6장 = 30장. 고려 `ch1~ch6`(서희 · 양규 · 강감찬 · 강화도 천도와 처인성 · 충주성 · 팔만대장경 · 삼별초), 조선 `j1~j6`(장 순서 j1 · j3 · j2 · j4 · j5 · j6), 근대 `k1~k6`, 일제 강점기 `i1~i6`, 현대 `h1~h6`.
- 장 흐름: 출정 카드 → 탐험(걸어 다니며 사람 · 안내판) → 미니게임 → 퀴즈 → (편 끝) 결과 카드. 역사 수첩, 화질 3단계, 저장(기기 안), 성능 측정판(`?perf=1`).
- 놀이: 고려 · 조선은 장별 놀이(카드 고르기 · 순서 맞추기 · 때 맞춰 누르기 · 획 따라 그리기 등), 근대~현대는 `chapters/kit/play.js`(drive · stops · deliver · find · ambush · sneak · collect · judge · build)와 역사책(book) · 문서(doc).
- 2026-10-26 3단계 완성도 작업(대사 52건 · 역사책 30건 · 그래픽 17건)까지 들어 있다. 마지막 전체 테스트 450개 모두 통과(그 판 기준).

## 3. 되돌린 「다시 만들기」 — 무엇을 했고 왜 되돌렸나 (다음 시작 때 참고)
**했던 일**(2026-10-26 ~ 27, 커밋 `7bd9b16` ~ `1aee44d`, 41개, 브랜치 기록에 남아 있음):
- 선생님 결정: "디테일 수정이 아니라 게임 기획을 다시, 재미 우선". 고려편을 시범으로 새로 만들고 다른 편은 놀이만 교체.
- 고려: 지킴이(편 내내 같은 주인공), 2장 성벽 지휘판 · 백성 호위, 1장 말 받아치기, 3장 둑 수위 · 귀주 신호, 새 4장 윤관 · 별무반 갈림길(새 출처 S71 · S72), 5장 처인성 당겨 쏘기, 6장 경판 공방 · 노 젓기 + 삼별초 합침, 장 순서 변경, 모자 · 투구 아래 얼굴 보이게.

**선생님 반응**(2026-10-27): 직접 해 보시고 "생각보다 내가 원하는 느낌이 아니라 당황스럽다" → "예전으로 다시 돌려야겠다".
**메인이 짐작한 까닭**(선생님이 확인해 주신 것은 아님 — 다음에 먼저 여쭐 것):

2. 꼭 듣는 대사를 7줄로 줄이고 놀이를 끼워 넣어 이야기 · 인물이 얇아졌다.

## 6. 클라우드(리눅스)에서 일하는 법
- 테스트: 전체 `NODE_PATH=$(npm root -g) PORT=8161 timeout 2400 node tools/test-node.cjs > 파일 2>&1` 뒤 `grep -E "FAIL|RESULT"`. 일부는 끝에 테스트 이름 앞부분 하나(`ch2`, `layout` 등). 전체를 한꺼번에 돌리면 가끔 시간 문제로 하나쯤 실패한다(따로 돌려 확인).
- 화면 확인: 작은 Node http 서버 + Playwright(`chromium.launch({ args: ['--use-angle=swiftshader', '--enable-unsafe-swiftshader'] })`, 1000×560), `index.html?debug=ch2-explore` 등. 개발 페이지에서 `window.__world` · `window.__ctx`.
- 포트가 겹치면 다른 번호를 쓴다. 서버는 PID로 끈다(`pkill -f`는 자기 셸까지 끊을 수 있다).
- 학생 사이트 · 백과사전 사이트는 이 클라우드에서 열리지 않는다(프록시 403). 선생님 기기 확인용 주소: `https://raw.githack.com/ssamgame/history/<커밋>/index.html`.
- 배포 순서는 `CLAUDE.md` '고친 뒤 올리는 순서' 그대로(전체 테스트 → `core/precache.js` 판 올림 + `tests/sw.test.js` → main 병합 · push → 판 번호 확인). **승인 뒤에만.**
