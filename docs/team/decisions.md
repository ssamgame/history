- 1장 부딪힘: 천막(2.35)·수레(몸+앞 채)·모닥불(1.35)·지휘소 마루(셋)를 실제 크기로, 거란 천막도(물러나며 걷으면 뺀다).
- 미리보기 index.html은 게시 때 바깥 뼈대가 붙으므로 title·css·importmap·#stage·#ui·main.js만(학생 사이트 index.html은 그대로).
- 첫 화면 시대 버튼을 누르면 바로 시작(기록 있으면 이어하기, 없으면 이름 → 지도).
- 서희가 기다리면 머리 위 「따라와!」, 강가에서 다리 아닌 곳으로 밀면 「강은 다리로 건너자!」, 바닥 화살표를 크고 밝게(맥박).
- 목표(없으면 가장 가까운 느낌표 인물)가 화면 밖이면 화면 가장자리에 가리키는 화살표(`world.offscreenTarget`, `hud.setEdge`).
- 대화 카메라가 비추는 인물의 느낌표는 대화 동안 숨긴다.
