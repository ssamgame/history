# 결정 기록 (기획 담당 → 개발·검토 담당)

선생님과 기획 담당이 정한 것만 적는다. 개발·검토 담당은 상태가 '대기'인 항목만 만든다.
형식은 `.claude/agents/planner.md` 참고. 상태: 대기 / 개발 중 / 확인 대기 / 끝

## D-1 (2026-10-27) 진행 원칙
- 선생님 결정: 느낌은 "걸어 다니며 사람을 만나는 이야기 중심". 놀이의 의미와 재미도 어느 정도 중요. 놀이는 선생님과 상의해서 정한다(메인·개발이 혼자 정하지 않음). 고려 1장부터 현대 6장까지 한 장씩 진행. 지난번 어색했던 까닭은 "상의 없이 놀이가 정해진 느낌".
- 대상: 고려 1장(ch1)부터 현대 6장(h6)까지 순서대로
- 할 일: 한 번에 한 장만. 기획 담당이 선생님과 그 장의 이야기·놀이를 정한 뒤 지시서를 쓰고, 개발 담당은 만든 뒤 사진 2장(마을 1, 미니게임 안 1)으로 보여 드린다. 선생님이 좋다고 한 뒤에만 다음 장.
- 하지 않을 것: 여러 장 동시 작업, 선생님과 상의 없이 놀이 정하기, 배포판(v65) 30장 덮어쓰기, 승인 전 main 병합·배포
- 확인 방법: 장마다 사진 2장과 선생님 말씀
- 상태: 끝 (진행 원칙)

## D-2 (2026-10-27) 고려 1장 시점 시험판 B·C
- 선생님 결정: B(1인칭·3인칭 바꾸기)와 C(어깨 가까이 낮은 3인칭) 둘 다 시험. 고려 1장 걸어 보는 시험판을 선생님 기기 주소로 받기. 토큰은 적게 쓰는 방향.
- 대상: 고려 1장(ch1) 탐험
- 할 일: B·C 두 가지 시점 시험판을 만든다. 탐험만 대상, 미니게임은 지금 그대로. 테스트는 고려 1장 관련만 돌린다(전체 테스트 하지 않음). 선생님 기기에서 열 주소를 드린다.
- 하지 않을 것: 다른 장 변경, 미니게임 변경, 전체 테스트, main 병합·배포
- 확인 방법: 선생님이 시험판 주소에서 B·C를 걸어 보고 고르신다
- 상태: 끝 (선생님: 둘 다 별로, 쓰지 않음)

## D-3 (2026-10-27) 모자·투구 아래 얼굴 보이게 다시 가져오기
- 선생님 결정: 얼굴 보이게 고친 것을 지금 3인칭에도 똑같이 적용(모든 시점).
- 대상: 모든 편 모자·투구 (커밋 f253bcf)
- 할 일: f253bcf를 현재 작업 브랜치에 다시 가져오고, 3인칭·1인칭 모두에서 얼굴이 보이게 한다. 관련 테스트만 돌린다.
- 하지 않을 것: 다른 다시 만들기 커밋 가져오기, 표정 바꾸기(늘 근엄하게)
- 확인 방법: 선생님이 모자·투구 쓴 인물의 얼굴이 보이는지 확인
- 상태: 끝

## D-4 (2026-10-27) 고려 1장 몰입감 시험 (조작은 그대로)
- 선생님 결정: 카메라 높이는 ②조금 낮게(오프셋 0,6,9). ㉮(낮고 가까운 카메라) ㉲(대화 때 얼굴 가까이) ㉱(장 시작 들어가는 짧은 장면) 셋 다 넣어 시험. 고려 1장에서만, 주소에 ?try=1일 때만 켜짐. B·C 시점은 쓰지 않음.
- 대상: 고려 1장(ch1), core/world.js 카메라
- 할 일: ?try=1일 때만 CAM_OFFSET 0,6,9, 대화 때 얼굴 가까이, 장 시작 3~5초 들어가는 장면. 조작(조이스틱=화면 방향)은 그대로. D-2의 B·C 시점 코드는 지운다. 고려 1장 관련 테스트만.
- 하지 않을 것: ?try=1 없을 때의 변화, 다른 장, 미니게임, 전체 테스트, main 병합·배포
- 확인 방법: 선생님이 ?try=1 주소와 기존 주소를 비교해 걸어 보신다
- 상태: 끝 (선생님: 낮은 카메라·시작 구도 좋음, D-5로 정식 반영)

## D-5 (2026-10-27) 고려 1장 정식 반영: 낮은 카메라 · 정면 대화 · 시작 장면
- 선생님 결정: 낮은 카메라와 시작 구도가 마음에 든다. 대화는 비스듬히가 아니라 정면을 보고 얘기하는 구도로. 시작 장면 길이는 적당. 시작 장면에 문을 열고 그 장소로 들어오는 움직임을 넣고, 길 바로 옆에 들어온 장소의 이름 안내판을 세운다. 이제 고려 1장으로 넘어간다.
- 대상: 고려 1장(ch1), 이후 모든 장에 다시 쓰기 쉽게(core/world.js 등)
- 할 일: ?try=1 조건 없이 정식 적용: 카메라 오프셋 0,6,9, 대화는 정면 구도, 시작 장면(진영 문이 열리고 걸어 들어옴, 약 4초, 건너뛰기 가능) + 문 지나 길 옆 장소 이름판. 고려 1장 관련 테스트만.
- 하지 않을 것: 다른 장 변경, 전체 테스트, main 병합·배포
- 확인 방법: 선생님이 고려 1장을 걸어 보신다
- 상태: 개발 중

## 상시 규칙 (앞으로 장을 만들 때마다, 선생님이 별도 지시를 안 하면 같이 반영)
- 카메라: 낮은 카메라 오프셋 (0, 6, 9)
- 시작 장면: 문을 열고 그 장소로 들어오는 움직임, 약 4초, 건너뛰기 가능. 문을 지나면 길 바로 옆에 들어온 장소의 이름 안내판.
- 대화: 비스듬히가 아니라 정면 구도.
- 조작(조이스틱=화면 방향)은 지금 배포판 그대로. 한 장씩 만들고 사진 2장으로 보여 드린 뒤 확인받는다.
