## 5. 클라우드(리눅스)에서 일하는 법

- 테스트(전체 약 6~10분):
  ```
  NODE_PATH=$(npm root -g) PORT=8161 timeout 2400 node tools/test-node.cjs            # 전체
  NODE_PATH=$(npm root -g) PORT=8161 timeout 900  node tools/test-node.cjs 'people'   # 일부(이름 접두)
  ```
  - 기본 실행기는 묶음마다 PORT부터 몇 개 포트를 쓴다. 그래서 팀원 둘이 동시에 돌리면 포트가 겹칠 수 있다(8161·8163처럼 떨어뜨리거나 차례대로 돌린다).
  - 출력이 길면 파일로 받아 `FAIL|RESULT` 줄만 본다.
- 화면 확인: `python3 -m http.server 8175`로 서버를 띄운 뒤 Node + Playwright(`chromium.launch({args:['--use-angle=swiftshader']})`, 1000×560)로 찍는다.
  - `?debug=k2-explore`처럼 장면부터 볼 수 있다.
  - `tools/diorama-gallery.html?only=hwangudan,forum`로 역사책 그림만 볼 수 있다.
  - `tools/book-preview.html?ch=k4&page=3`로 역사책 한 쪽을 볼 수 있다.
  - `tools/arena-gallery.html?ch=i2&i=0&view=play`로 미니게임 무대를 볼 수 있다.
- 서버를 끌 때는 `pkill -f`를 쓰지 말고 PID로 `kill`한다(자기 셸까지 끊긴다).
- 커밋: 한국어 메시지를 쓴다. 팀원이 여럿이면 `git add -A` 대신 자기 파일만 골라 `git add`한다. 끝에 attribution 두 줄을 붙인다.
- 사용량 한도(5시간)에 걸리면 팀원이 멈춘다. 초기화 뒤 SendMessage로 같은 팀원에게 "멈춘 곳부터 이어서"라고 보내면 이어 간다.
